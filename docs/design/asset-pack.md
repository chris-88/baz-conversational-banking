# Baz / BOI POC Asset Pack

Developer-ready SVG and PNG assets derived from the POC visual direction.

## Folders
- `logos/` — Baz assets and a BOI **placeholder** mark/wordmark.
- `icons/product/` — banking product icons.
- `icons/navigation/` — bottom navigation.
- `icons/status/` — application states.
- `icons/utility/` — common UI actions.
- `illustrations/` — hero and supporting illustrations in SVG + PNG.
- `backgrounds/` — reusable hero/background assets.
- `avatars/` — synthetic customer and partner avatars.
- `app-icons/` — PWA/app icon sizes.
- `tokens/` — CSS/JSON design tokens, asset mapping and PWA manifest.
- `reference/` — generated mockups and design boards.

## Brand note
The BOI mark/wordmark in this pack is a POC placeholder generated from the concept. Replace it with official Bank of Ireland brand artwork supplied internally before external or production use.

## Usage
Prefer SVG in the site/app. PNGs are supplied for convenience and raster-only contexts. No font files are included.
