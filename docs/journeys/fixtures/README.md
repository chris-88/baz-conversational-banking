# Journey fixtures

Where the captured journey data actually lives, and why it is not in this directory.

## The form snapshots

```text
supabase/functions/_shared/tenants/boi/forms/form-1833.json    707KB, 499 fields
supabase/functions/_shared/tenants/boi/forms/form-1940.json    444KB, 418 fields
```

They live beside the tenant rather than in `docs/` because the Edge Functions import them
directly at build time. Moving them here would mean a function importing from a documentation
directory, which is the wrong direction of dependency.

Regenerate with:

```bash
node scripts/fetch-form-definition.ts <formId>
```

Each snapshot carries its own provenance — source URL, retrieval timestamp, the form's own version
string, a hash of the bytes, and the page location where the genuine journey is completed.
