# Baz Dev Kit

This pack contains the recommended Baz logo direction:
a stylised lowercase **b** with the Baz face inside it, plus the supporting face mark,
wordmark, lockup and app icon.

## Included
### SVG
- baz-b-icon.svg
- baz-face-mark.svg
- baz-wordmark-horizontal.svg
- baz-wordmark-horizontal-blue.svg
- baz-wordmark-monochrome.svg
- baz-lockup.svg
- baz-app-icon.svg

### Tokens
- tokens/brand-tokens.json
- tokens/brand-tokens.css

### Docs
- docs/implementation-notes.md

## Recommended use
- Landing / hero: `baz-wordmark-horizontal.svg`
- Small header: `baz-lockup.svg`
- Chat avatar / zero-state: `baz-face-mark.svg`
- Monogram / compact brand mark: `baz-b-icon.svg`
- PWA / homescreen icon: `baz-app-icon.svg`

## Colour
- Primary: #1D4ED8
- Ink: #0F172A

## Note
The `az` wordmark is supplied as a clean starter asset using SVG text.
If you want, this can later be refined into a final bespoke outlined logotype.
